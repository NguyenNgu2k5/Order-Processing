# Order Processing and Refund API

Backend REST API for e-commerce order processing and refund management.

## Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- PostgreSQL
- Flyway
- Maven
- Docker

## Requirements

- Java 21
- Docker
- Docker Compose
